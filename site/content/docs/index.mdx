# A connected approach to software delivery

<p className="cajon-page-lead">The Harmonic Method is a single, named method for building software where intent is explicit, durable, and preserved across handoffs. It is the delivery method built for <a href="/docs/ai-coding-agents">AI coding agents</a> — the operating model for AI-native software delivery, where agents, not engineering capacity, set the pace.</p>
