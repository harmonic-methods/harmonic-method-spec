---
title: Apply the method to a new initiative
description: Work through Explore and Compose, then plan how to deliver the capability.
---

Choose an initiative with a specific outcome and use these guides to work through [Explore and Compose](/docs/method/quality#phases).

## The pathway [#steps]

1. [Capture Notes](/docs/getting-started/capture-notes) to preserve the facts, boundaries, and choices that shape the work.
2. [Define a Coda](/docs/getting-started/define-a-coda) that says what will be true when you succeed.
3. [Define a Capability Beat](/docs/getting-started/define-a-beat) for each capability the System needs to reach the Coda.
4. [Run a Coda check](/docs/getting-started/run-a-coda-check) on each Beat, then review the set for gaps and overlap.

## Check which function is unowned [#functions]

Before starting, name who holds each of the [six roles](/docs/method/roles). One person can hold several functions. Give each function an owner wherever the work needs it.

## Move into implementation [#implementation]

When the capability is clear enough to deliver, [plan Beat Versions and deliver Revisions](/docs/implementation/plan-beat-versions).
