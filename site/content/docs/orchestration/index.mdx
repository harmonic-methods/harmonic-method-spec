## What Harmonic Orchestration addresses

Harmonic Composition ensures that a single system has a clear destination, durable capability definitions, and structured context that survives handoffs. Harmonic Orchestration operates at the next level up: when multiple systems, teams, or agents are executing in parallel, it provides the coordination layer that keeps them aligned to shared intent.

The questions Orchestration is designed to answer:

- How do human and AI agents divide and hand off work without losing context at the boundary?
- How does a team know which agent is working on what, and whether it is still on track?
- How are decisions made by one agent surfaced to others who need them before work diverges?
- How does shared context get maintained as the number of active agents scales?
