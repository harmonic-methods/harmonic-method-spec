## How the four concepts relate

The [Coda](/docs/composition/coda) establishes where the system is headed. [Capability Beats](/docs/composition/beats), or Beats, define the durable capabilities needed to get there. Each Beat is planned through one or more [Beat Versions](/docs/composition/beat-versions), which carry the description, scope, and acceptance criteria for a slice of the capability. Revisions deliver each Beat Version incrementally, one pull request at a time. [Notes](/docs/composition/notes) carry the context that keeps all of these coherent — across handoffs, over time, and through changes in the people doing the work.
