# What Is AI-Native Software Delivery?

<p className="cajon-page-lead">AI-native software delivery is an approach to building software where AI agents perform most of the execution and the delivery method optimizes for what becomes scarce as a result: clear, durable, structured intent. It is not "software delivery plus some AI" — it is delivery designed from the ground up for a world where execution is cheap and direction is the hard part.</p>

<div className="cajon-def-box">
  <div className="cajon-def-box__label">Definition</div>
  <p><strong>AI-native software delivery</strong> is software delivery built around AI agents as the primary executors, with people owning intent, judgment, and review. Because execution is no longer the bottleneck, an AI-native approach optimizes for explicit destinations, durable capability definitions, and preserved reasoning — the inputs agents need to build the right thing. Harmonic Methods is the <strong>software delivery framework</strong> and <strong>AI development methodology</strong> built for this model.</p>
</div>

## Why "AI-native" and not just "AI-assisted"

Most teams today are AI-*assisted*: they bolt agents onto a delivery process that still assumes humans write the code. The planning artifacts, the cadence, and the quality bar were all designed for human execution; the agent is a faster typist inside an unchanged system.

AI-*native* delivery starts from the opposite premise. If agents do the execution, then the delivery method's primary job is no longer to divide work into human-sized pieces — it is to produce intent that agents can reason about. That reframing changes what the planning layer must contain and what "good" looks like.

## Harmonic Methods: a software delivery framework for the AI era

Harmonic Methods is the methodology — and the software delivery framework — purpose-built for AI-native software delivery. Its founding framework, [Harmonic Composition](/docs/composition), supplies the primitives the model requires:

- A **Coda** as the explicit destination.
- **Beats** as durable, outcome-oriented capability definitions — the structured intent [AI coding agents](/docs/ai-coding-agents) build against.
- **Notes** as preserved, typed reasoning.
- **Quality gates** that define when intent is good enough to build.

As an **AI development methodology**, it is adopted incrementally and coexists with a team's existing ceremonies — adding the intent and context layer that AI-native delivery depends on. AI-native delivery is the destination; Harmonic Methods is how teams get there.
