# Glossary

<p className="cajon-page-lead">Concise definitions of the key terms used across the Harmonic Method. Each entry links to the full documentation for that concept.</p>

<ul className="cajon-glossary-list" aria-label="Harmonic Method terms">

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">AI-Native Software Delivery</span>
    <span className="cajon-glossary-def">An approach to building software where AI coding agents perform most execution against an explicit, structured representation of intent, while people own the destination, tradeoffs, and review. The Harmonic Method is the delivery method built for it. <a href="/docs/ai-coding-agents">Learn more →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Composition</span>
    <span className="cajon-glossary-def">How the Composer function of the Harmonic Method delivers continuous, coherent software — preserving context, capability, and intent across handoffs. <a href="/docs/composition">Learn more →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Harmonic Methods</span>
    <span className="cajon-glossary-def">The corporate name and certification body behind The Harmonic Method — one method with named functions — Composer, Orchestrator, Conductor, Producer — and the canonical domain, harmonicmethods.com. <a href="/docs">Return to the hub →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Orchestration</span>
    <span className="cajon-glossary-def">How the Orchestrator and Conductor functions of the Harmonic Method coordinate human and AI agents to execute against shared context across systems and teams.</span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Portfolio Management</span>
    <span className="cajon-glossary-def">How the Producer function of the Harmonic Method operates at portfolio altitude — mapping and arranging capabilities across the wider landscape, managing a portfolio of systems and initiatives in alignment with strategic intent.</span>
  </li>

</ul>

## Composition

<ul className="cajon-glossary-list" aria-label="Composition terms">

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Beat Version</span>
    <span className="cajon-glossary-def">The planning increment of a Beat — a planned slice of its capability, carrying the description, scope, and acceptance criteria for a unit of planned work. A Beat Version is delivered through one or more Revisions. <a href="/docs/composition/key-concepts#beat-versions">Learn more about Beats →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Capability Beat (Beat)</span>
    <span className="cajon-glossary-def">A durable, outcome-oriented capability that keeps its identity as it evolves through Beat Versions and works coherently with other capabilities toward the system’s Coda. Capability Beats are called Beats for short; the name does not imply a fixed delivery interval. <a href="/docs/composition/beats#why-capability-beat">Why Capability Beat? →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Clear</span>
    <span className="cajon-glossary-def">One of the six quality dimensions. A Beat is Clear when its intent and scope are unambiguous and can be understood by anyone working in the system without additional explanation. <a href="/docs/composition/quality-gates">See all quality dimensions →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Coda</span>
    <span className="cajon-glossary-def">The specific, resolved end-state the system converges toward. The Coda defines what <em>done</em> looks like for the current phase of delivery and shapes which Beats are relevant. <a href="/docs/composition/key-concepts#coda">Learn more about Coda →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Distinctive</span>
    <span className="cajon-glossary-def">One of the six quality dimensions. A Beat is Distinctive when it represents a capability that stands apart from others in the system without unnecessary overlap. <a href="/docs/composition/quality-gates">See all quality dimensions →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Durable</span>
    <span className="cajon-glossary-def">One of the six quality dimensions. A Beat is Durable when it is expected to remain relevant throughout the current phase and beyond, not rendered obsolete by its first Revision. <a href="/docs/composition/quality-gates">See all quality dimensions →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Harmonious</span>
    <span className="cajon-glossary-def">One of the six quality dimensions. A Beat is Harmonious when it integrates cleanly with the other Beats and supports, rather than conflicts with, the overall Coda. <a href="/docs/composition/quality-gates">See all quality dimensions →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Notes</span>
    <span className="cajon-glossary-def">Explicit, versioned, discoverable context that preserves the reasoning behind the work. Every Note has a type: Context, Constraint, Guidance, Decision, or Document. <a href="/docs/composition/key-concepts#notes">Learn more →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Quality Gates</span>
    <span className="cajon-glossary-def">The six dimensions — Distinctive, Harmonious, Substantial, Durable, Clear, and Strategically Aligned — that every Beat must satisfy before it can transition to <code>composed</code> and Revisions begin. <a href="/docs/composition/quality-gates">Learn more →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Revisions</span>
    <span className="cajon-glossary-def">Shippable increments that evolve a Beat while preserving continuity. Each Revision advances a capability without pivoting or discarding what has already been established. <a href="/docs/composition/key-concepts#beat-versions">Learn more →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Strategically Aligned</span>
    <span className="cajon-glossary-def">One of the six quality dimensions. A Beat is Strategically Aligned when it advances the system toward the Coda and reflects the priorities of the current phase. <a href="/docs/composition/quality-gates">See all quality dimensions →</a></span>
  </li>

  <li className="cajon-glossary-entry">
    <span className="cajon-glossary-term">Substantial</span>
    <span className="cajon-glossary-def">One of the six quality dimensions. A Beat is Substantial when it addresses a capability of genuine, lasting significance rather than a thin or incidental concern. <a href="/docs/composition/quality-gates">See all quality dimensions →</a></span>
  </li>

</ul>
