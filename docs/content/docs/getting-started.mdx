# Getting Started

<p className="cajon-page-lead">The Harmonic Method is one method with named functions, scoped by altitude. The right starting point depends on the scope of the problem you are addressing. This guide helps you orient.</p>

## Start with Composition

If you are working on a single software system, product, or engagement and want a structured approach to delivery that preserves context and maintains coherence across handoffs, [Composition](/docs/composition) is your entry point.

It is the founding area of the Harmonic Method and the most fully documented. Every other function builds on concepts it establishes.

## When to consider Portfolio Management

If you are managing multiple delivery threads, systems, or initiatives simultaneously and need a structured way to maintain strategic alignment across them, Portfolio Management is the relevant layer.

Portfolio Management is designed to sit above Composition: it provides the strategic context, the broader Codas and capability directions, that individual systems reflect in their own delivery. It is currently in development.

## When to consider Orchestration

If delivery is distributed across multiple teams and systems that must coordinate without centralized control, Orchestration addresses the interface between those systems: shared context, dependency sequencing, and alignment recovery.

Orchestration assumes Composition is in use within each system. It is currently in development.
